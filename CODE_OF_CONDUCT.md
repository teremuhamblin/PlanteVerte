# Code of Conduct — PlanteVerte

## 1. Mission
PlanteVerte est un projet éducatif et communautaire visant à aider les utilisateurs à mieux comprendre, suivre et prendre soin de leurs plantes. Le respect, la collaboration et la bienveillance sont essentiels.

## 2. Comportements attendus
- Respect mutuel entre contributeurs.
- Communication claire, constructive et sans agressivité.
- Aucune discrimination (origine, genre, âge, handicap, religion, orientation).
- Aucune attaque personnelle, harcèlement ou intimidation.

## 3. Comportements interdits
- Contenu offensant, violent ou discriminatoire.
- Spam, publicité ou comportements perturbateurs.
- Diffusion de données personnelles sans consentement.

## 4. Signalement
Les problèmes peuvent être signalés via :
- Issues GitHub (catégorie “Conduct”)
- Contact direct avec le mainteneur du projet

## 5. Application
Les mainteneurs peuvent :
- Avertir
- Suspendre temporairement une contribution
- Bannir définitivement en cas de récidive

Merci de contribuer à un environnement sain et professionnel.
