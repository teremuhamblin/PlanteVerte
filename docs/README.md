# PlanteVerte
- docs
Assistant Android pour apprendre à connaître ses plantes, les suivre dans un journal, et les analyser via un scanner IA.

### Fonctionnalités
- Assistant plante (PlantWizard)
- Journal des plantes
- Scanner IA (analyse d’image)
- Rappels d’arrosage
- Synchronisation cloud (Firebase)
- Export PDF du journal
