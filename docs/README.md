# PlanteVerte
- docs
   - Assistant Android pour apprendre à connaître ses plantes, les suivre dans un journal, et les analyser via un scanner IA
   - Ce dossier contient toute la documentation technique, fonctionnelle et visuelle du projet PlanteVerte.  
Il sert de référence pour les développeurs, contributeurs et mainteneurs.

---

### 📁 Contenu du dossier
#### 1. Design System (`design-system/`)
Contient les éléments visuels et les règles d’interface :
- `colors.md` — palette officielle PlanteVerte  
- `typography.md` — styles de texte  
- `components.md` — composants UI (boutons, cartes, listes, etc.)

### 2. Intelligence Artificielle (`ai/`)
Documentation liée au scanner IA :
- `model-training.md` — entraînement des modèles  
- `scanner-ia-architecture.md` — architecture du module IA

### 3. Cloud & Synchronisation (`cloud/`)
Documentation pour la synchronisation des données :
- `firebase-structure.md` — organisation Firestore  
- `sync-protocol.md` — protocole de synchronisation local ↔ cloud

---

## 🎯 Objectifs du dossier
- Centraliser toute la documentation du projet  
- Faciliter la contribution et la maintenance  
- Décrire les modules avancés (IA, cloud, design system)  
- Servir de base pour l’évolution du projet (v1.0 → v5.0)

---

### 📌 Bonnes pratiques
- Chaque fichier doit être clair, concis et structuré.  
- Toute modification majeure doit être documentée.  
- Les schémas, diagrammes et exemples sont encouragés.  
- Les fichiers doivent rester indépendants et faciles à lire.
